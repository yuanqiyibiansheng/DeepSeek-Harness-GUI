# ui-angelina

Optional Angelina theme plugin for the DSH web client.

## What it does

- Registers Angelina light and dark theme ids in the client theme registry.
- Injects the Angelina visual stylesheet at runtime.
- Exposes a General settings row so the theme is opt-in and removable.

## Notes

- This plugin only affects users who install and select the Angelina theme.
- Default theme behavior stays unchanged.
